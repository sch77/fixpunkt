# Fixpunkt

Schnelllesen Wort für Wort: Fixpunkt zeigt Texte und PDFs Wort für Wort an fester Stelle.

https://sch77.github.io/fixpunkt/

Texte, Dateien und Lesestand bleiben im Browser. Geteilte Inhalte kommen über den Adressanhang
oder den Service Worker an und gehen nicht an den Server. PDFs liest pdf.js 3.11.174, das die Seite
von cdnjs nachlädt.

Schriften: Literata und Atkinson Hyperlegible Next, beide unter der SIL Open Font License 1.1,
eingebettet als Latin-Teilmenge.

Gebaut aus einer Quelle im Workspace des Betreibers; Änderungen hier werden beim nächsten
Veröffentlichen überschrieben.
